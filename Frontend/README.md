# Ejecución del proyecto

Para ejecutar el `frontend`, abre la carpeta frontend en Visual Studio Code o en tu IDE de preferencia, asegúrate de tener instalado Node.js (v18+), instala las dependencias ejecutando `npm install`, luego inicia el servidor de desarrollo local con `npm run dev` y abre en tu navegador la URL generada (normalmente `http://localhost:5173`).
